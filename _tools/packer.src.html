Скачать ZIP
  1. Распакуй ZIP (правой кнопкой → «Извлечь всё»). Внутри будет папка с файлами.
  2. Залей файлы на GitHub по партиям: всё сразу GitHub через браузер не берёт. Для каждой партии: открой её ссылку, перетащи только перечисленные файлы из папки , дождись загрузки и нажми зелёную Commit changes внизу.
  3. Через 1–2 минуты после последней партии страница готова:

Если папка с таким адресом уже была, новые файлы её заменят, а ссылка останется прежней. После обновления, если видна старая версия, обнови страницу с очисткой кэша (Ctrl+F5).
