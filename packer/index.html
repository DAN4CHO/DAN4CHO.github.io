Скачать ZIP
  1. Распакуй ZIP (правой кнопкой → «Извлечь всё»). Внутри будет папка .
  2. Открой страницу загрузки на GitHub (нужно быть залогиненным).
  3. Перетащи туда папку целиком, а не файлы из неё.
  4. Дождись, пока все файлы загрузятся, и нажми зелёную кнопку Commit changes внизу.
  5. Через 1–2 минуты страница будет готова:

Если папка с таким адресом уже была, новые файлы её заменят, а ссылка останется прежней. После обновления, если видна старая версия, обнови страницу с очисткой кэша (Ctrl+F5).

Всё считается у тебя в браузере, модель никуда не отправляется.
